## Setup Guide

### Archipelago

same steps as usual:

- download the APWorld and send it to the host
- install the APWorld using the archipelago launcher
- restart the launcher
- use the option creator in the launcher to create the yaml-options and send them to the host

### Client

- download the game client for your system, open it and execute the 
  `run_game.sh` or `run_game.bat` file (doubleclick on Windows)
- when the game has finished loading, press story. 
  A new menu should open
- wait for the host to create the game and send you server address and password 
- enter the server details (server address, slot name and password) and press connect

**WARNING: If you already have a player that has the same name as your slot name, 
the game will delete it and recreate the player, resetting all your campaign progress so choose your slot name wisely**
